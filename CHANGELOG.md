# Changelog

All notable changes are listed here. The project follows [Semantic Versioning](https://semver.org).

## [Unreleased]

### Kernels

- Modules `tensors`, `materials`, `elements`: Saint Venant-Kirchhoff, Neo-Hooke, modified Neo-Hooke and Mooney-Rivlin in the reference, current and two-point configurations, each computed in its own quantities, and element R and K for each. `material_set(lam, mu)` gives all four with matching small-strain constants.
- Batched material interface (`mat%ref|cur|mix` over all points of an element); two-pass element kernels.
- Element K assembled in 3x3 node blocks with the tangent-gradient product reused per node and the lower blocks mirrored.
- Element status flag (`ELEM_INVERTED`, `ELEM_DEGENERATE`) from one kinematics check per point; the material routines do not check det F.
- Reusable reference geometry (`geometry`, `reference_geometry`, optional `geo` of `elem_ref` and `elem_mix`).
- Any element of fortran_shapefuncs; no heap allocation per element with gfortran and ifx (tangents accumulate in place; `-fstack-arrays`).

### Material evaluation paradigms

- Module `materials_ad`, generated by `jax/python/export_fortran.py`: the four models differentiated by JAX and exported as plain Fortran, with a source hash checked in CI.
- Subpackage `jax/`: JAX automatic differentiation of Psi(I1, I2, J) through embedded Python.
- Subpackage `socket/`: FEAP-style socket server (fe_jax over TCP, synchronous) with a pure-Fortran POSIX client.
- `remote_material`: paradigms that evaluate elsewhere supply only `make` and `evaluate`; handles are compiled and verified once.

### Benchmarks and tests

- App `bench`: element and material time per model and configuration for the native, JAX-exported and cached-geometry paradigms; shared command line (FLAP) with element type, order and cubature degree; CSV output in long format.
- `tools/sweep.py`: every compiler, element and paradigm into `results/<timestamp>/` with an environment record, summary tables, plots and optional heap allocations per element.
- Test: finite differences of energy and residual, agreement of configurations and paradigms, rigid rotation, small strain and inverted elements on hex8, hex27, tet4, tet10 and wedge6; `src/harness.f90` holds the support shared by every package.

### Documentation and infrastructure

- fpm package with per-compiler debug and release profiles, `ci.sh`, GitHub CI on gfortran, ifx, LLVM flang and nvfortran; depends on fortran_shapefuncs v0.2.0 and FLAP v2.5.3.
- `llms.txt` (complete API reference, checked by `tools/check_docs.py` in CI), examples `demo_configurations` and `demo_inverted`, README and AGENTS.md.
- Typst notes: stresses and tangents of every model in every configuration, and the spatial tangent from tau(b).
